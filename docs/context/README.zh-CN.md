# 项目上下文索引

在 Codeseed 中开启新的模型 thread 时，先阅读这个目录。

这个目录是索引。保持它简洁，用链接指向聚焦文档，不要把所有项目知识都复制到这里。

## 起步阅读

1. 阅读 [AGENTS.md](../../AGENTS.md) 了解仓库级 agent 指令。
2. 修改命令行为、项目布局、状态文件、安装或更新流程前，阅读 [architecture.zh-CN.md](architecture.zh-CN.md)。
3. 修改 `src/` 下 Rust 源码前，阅读 [modules.zh-CN.md](modules.zh-CN.md)。
4. 修改代码、测试、文档或生成的 skill 内容前，阅读 [constraints.zh-CN.md](constraints.zh-CN.md)。
5. 处理 remote、branch、commit、push 或发布前，阅读 [git.zh-CN.md](git.zh-CN.md)。
6. 复用 helper 或增加抽象前，阅读 [components.zh-CN.md](components.zh-CN.md)。

- 当其它位置产生长期上下文时，在这里增加链接。
- 将详细解释放到聚焦文件中。
- 及时移除过期链接。
- 尽量维护对应的英文上下文文件。
